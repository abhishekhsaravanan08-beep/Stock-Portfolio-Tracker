# Stock Portfolio Tracker

A simple Python application that calculates the total investment value of a stock portfolio.

## Features
- Uses a hardcoded dictionary of stock prices
- Accepts user input for stock names and quantities
- Calculates total investment value
- Saves the portfolio report to a text file (`portfolio.txt`)

## Technologies Used
- Python

## How to Run

```bash
python stock_portfolio.py
```

## Sample Stocks
- AAPL
- TSLA
- GOOGL
- MSFT
- AMZN
